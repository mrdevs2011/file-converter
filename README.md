# File Converter

Sof HTML / CSS / JS. Python kerak emas.

## Ishlatish

`index.html` ni brauzerda oching.

1. Faylni tashlang, tanlang yoki Ctrl+V qiling.
2. Chapdan chiqish formatini tanlang.
3. Convert bosing.

## Oqiydi

JSON, JSONL, Excel (xlsx/xls/xlsm/xlsb), ODS, CSV, TSV, TXT, YAML, XML, HTML jadval, Markdown jadval.

## Yozadi

Excel, ODS, CSV, TSV, JSON, JSONL, YAML, XML, HTML, Markdown.

Bir nechta faylni birga qo'shib ham o'tkazadi.
Internet shart emas: kutubxonalar `vendor/` ichida.
